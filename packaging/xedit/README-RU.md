# Экспорт из xEdit в VoiceForge

Скрипт: **FishAI - Export VoiceForge CSV**.
Это первая публичная версия, проверенная пока на немногих плагинах. Если что-то выгрузилось неверно — сообщите, приложив последние строки вкладки Messages.

## Как запустить

1. Запустите ваш xEdit через MO2. Для Skyrim SE программа на диске называется SSEEdit.exe / SSEEdit64.exe — это и есть xEdit.
2. Загрузите нужный ESP/ESM/ESL и его мастера. Для полного учёта NPC, алиасов и сцен нужны содержащие их плагины. Оставьте построение Reference Info включённым и дождитесь завершения загрузки.
3. Слева выделите **нужный плагин целиком**. Правой кнопкой → **Apply Script**.
4. Выберите **FishAI - Export VoiceForge CSV**, нажмите OK.
5. Выберите папку для результатов. Скрипт создаст в ней отдельную папку `VoiceForge-ГГГГММДД-ЧЧММСС`, не перезаписывая прошлый экспорт.
6. В сообщениях xEdit появятся путь, количество ответов, целевых файлов и замечаний.
7. Сначала откройте `EXPORT-REPORT.txt` и `review.csv`. В VoiceForge: **+ Новый проект → Пара CSV**; выберите `lines.csv` и `paths.csv` из этой папки. Папку самого проекта укажите отдельно.

Выделение Dialogue Topic / отдельных INFO также ограничивает экспорт выбранными записями. Выделение одного Quest не выбирает все связанные INFO автоматически: для первого раза выбирайте весь плагин.

`FishAIExportCore.pas` — служебная библиотека, её не нужно запускать отдельно. Оба PAS-файла должны находиться рядом.

## Что получается

- `lines.csv`: INFO, настоящий номер ответа, текст, needs_voice, исходные субтитры. Заголовки соответствуют импортёру VoiceForge.
- `paths.csv`: Data-relative `Sound/Voice/Plugin/VoiceType/file.fuz`, ключ реплики и голос. Дополнительные поля показывают способ определения и контекст shared-реплики.
- `review.csv`: неразрешённые голоса/алиасы/родительские записи, текст для ручной проверки, кандидаты общих голосов и спорное владение аудио у overrides.
- `EXPORT-REPORT.txt`: счётчики и ограничения.

Скрипт читает выбранные INFO и их победителей среди **загруженных в эту сессию xEdit** плагинов. Это не обязательно весь активный load order MO2, если вы загрузили только часть. Ключи и имена FUZ используют локальный FormID, включая ESL; номер ответа берётся из TRDT. Длинные Quest/Topic имена обрезаются по алгоритму штатного `Export dialogues.pas` из xEdit. Shared Info читаются через DNAM, голоса определяются по контексту пользователя shared-реплики.

CSV записываются в UTF-8, поля с кавычками/запятыми/переносами экранируются. Русский текст берётся таким, каким его декодировал xEdit: сначала убедитесь, что кириллица правильно видна в самом xEdit.

## Что определяется автоматически и где нужна проверка

Учитываются явный Speaker, положительные GetIsID/GetIsVoiceType, часть фильтров по расе/классу/фракции/полу, условия INFO и диалога квеста, AND/OR-группы, статические квестовые алиасы и участники сцен. Поддержаны ссылки на FLST и наследование голоса по флагу Use Traits.

Это **проекция условий на набор голосов**, а не симулятор всей игры. Например, пересечение двух множеств голосов может быть шире множества NPC, действительно удовлетворяющих обоим условиям. Для общих реплик без явного говорящего используются кандидаты VTYP с Allow Default Dialog; это явно отмечается в review.csv. Не запускайте массовый синтез таких кандидатов без проверки покрытия.

Динамические алиасы, назначаемые Papyrus, и голоса, доступные только через цепочки LinkTo, нельзя считать достоверно восстановленными этим скриптом. Неразрешённый участник сцены пропускается с записью в отчёт. Для INFO, переопределённых другим плагином, путь аудио без сверки с существующим loose/BSA не угадывается: реплика остаётся в lines.csv, а причина попадает в review.csv. **Строки lines.csv без paths.csv не создадут задания в программе.**

Выгружаются все типы голоса, включая детские (MaleChild, FemaleChild), — по тем же условиям, что и остальные. Пустой текст и чистая пунктуация получают needs_voice=no. В колонке voice_text (то, что озвучит Fish) вырезаются ремарки [..], <..> и *..*; субтитр subtitle_text остаётся как в игре. Такие строки и строки с круглыми скобками отмечаются в review.csv. Реплики в темах без EditorID (общие ванильные темы) экспортируются с именем файла <квест>__<FormID>_<n>.fuz, как в игре. Написание пути само по себе не подтверждает существование звукового файла или полноту набора голосов.

Экспортёр не создаёт эталоны речи и не извлекает WAV из BSA. Голосовую библиотеку ref_candidates.json + refs либо Fish reference_id нужно выбрать отдельно. API-ключ ему не нужен. Синтез, изменения ESP, установка модов и сетевые обращения не выполняются.

## Если появилась ошибка

Сохраните последние строки вкладки Messages с номером строки/ошибкой. Не сохраняйте изменения плагинов ради CSV: экспортёр их не меняет. При частичном экспорте сохраните папку для диагностики и повторяйте в новую папку. Не правьте форматы заголовков.

## Установка и удаление

Скопируйте оба PAS-файла вместе в папку `Edit Scripts` вашего xEdit (при запуске 64-битной версии из MO2 — в ту папку `Edit Scripts`, что лежит рядом с её EXE). Для отключения достаточно не выбирать скрипт; удаление его файлов не меняет моды и созданные CSV.

Документация xEdit: https://tes5edit.github.io/docs/13-Scripting-Functions.html
Официальный исходный код: https://github.com/TES5Edit/TES5Edit

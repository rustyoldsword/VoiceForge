VoiceForge 0.4.1 — студия озвучки Skyrim от Dwemer Mods (https://dwemermods.com)

Запуск: откройте VoiceForge.exe.
Папка _internal должна оставаться рядом с EXE. Устанавливать Python не требуется.
Язык интерфейса: Настройки → Язык интерфейса (меняется после перезапуска).

Первый проект:
1. «Настройки»: укажите папку инструментов (LipGenerator.exe, xWMAEncode.exe, ffmpeg.exe
   и FonixData.cdf) и свой локальный файл с FISH_API_KEY либо задайте переменную окружения.
   Сохраните настройки (проект для этого не нужен; их получит каждый проект).
2. Выгрузите диалоги скриптом xEdit из папки xEdit Scripts\ (он создаёт папку VoiceForge-...).
3. Перетащите эту папку на окно VoiceForge или на VoiceForge.exe (или нажмите «Из выгрузки xEdit…»).
   Библиотека ванильных голосов из папки voices\ подключается сама.
4. Проверьте окно проекта и нажмите «Создать проект». Проект создаётся рядом с выгрузкой и сразу открывается.
   (Ручной импорт: «+ Новый проект» с lines.csv + paths.csv или jobs.json.)
5. Начните с «5 проб WAV», прослушайте их в очереди реплик, затем запустите конвейер.

Результаты записываются в output\ внутри проекта.
templates\ — шаблоны и примеры входных данных, инструкция.
xEdit Scripts\ — экспортёр, который выгружает lines.csv + paths.csv прямо из плагина.
voices\ — эталоны ванильных голосов. Внешние инструменты и API-ключ в комплект не входят.

Полное описание (англ.): README.md. Экспортёр xEdit: xEdit Scripts\README-RU.md.
Не публикуйте свои проекты, файлы ключей, логи, базы очереди и скриншоты с личными путями.
